## Clasificación de pruebas

### Validaciones de dominio

Incluyen reglas como:

- mínimo no puede superar máximo;
- responsable debe pertenecer a la sección;
- códigos únicos;
- tratamiento de valores ausentes;
- interpretación del Excel.

### Integración

Las pruebas Django verifican en conjunto:

- modelos;
- ORM;
- formularios;
- vistas;
- autenticación;
- autorización;
- importación;
- relaciones entre entidades.

Django crea una base de pruebas temporal para aislar estos escenarios.

### Flujo web

El `Django Test Client` realiza solicitudes HTTP contra las vistas reales del sistema para comprobar:

- login;
- autorización;
- creación;
- consulta;
- búsqueda;
- filtros;
- rechazo de operaciones.

La revisión visual de la interfaz se realiza manualmente de forma adicional.
