# Evidencia P16: paginacion y filtros CMDB

Fecha: 28 de octubre de 2026.

Responsable: Erick Noe Gomez Lopez, 201700866.

Entorno:
- Windows.
- Docker Desktop.
- Django.
- PostgreSQL.
- Base de datos persistente con 5000 dispositivos.

## Objetivo

Comprobar la paginacion sobre 5000 dispositivos y medir
los tiempos observados de consultas Django ORM.

## Entrada

- Total de dispositivos: 5000.
- Tamano de pagina: 30 registros.
- Paginas evaluadas: 1, 84 y 167.
- Filtro evaluado: clasificacion SERVIDOR.

## Herramienta y comando

Se ejecuto docker compose exec -T web python manage.py shell -c
con Paginator de Django y time.perf_counter.

Las mediciones se realizaron dentro del contenedor de Django,
contra la base de datos PostgreSQL.

## Resultados obtenidos

Base de datos: postgresql.

Dispositivos encontrados: 5000.

Paginas disponibles: 167.

Pagina 1:
- Registros: 30.
- Tiempo observado: 25.573 ms.

Pagina 84:
- Registros: 30.
- Tiempo observado: 72.322 ms.

Pagina 167:
- Registros: 20.
- Tiempo observado: 27.621 ms.

Filtro SERVIDOR:
- Dispositivos encontrados: 1000.
- Registros consultados: 30.
- Tiempo observado: 32.064 ms.

## Evaluacion

Los resultados coinciden con los conteos esperados.

Se comprobo la paginacion y el filtro sobre datos persistidos.

Los tiempos corresponden a consultas Django ORM e incluyen
la obtencion de registros.

No representan latencia HTTP ni garantias de rendimiento.

La medicion no modifico datos de la CMDB.

## Criterio de aceptacion

- Al menos 5000 dispositivos: cumplido.
- Paginacion de 30 registros: cumplido.
- Ultima pagina con 20 registros: cumplido.
- Filtro SERVIDOR con 1000 dispositivos: cumplido.
- Tiempos reales observados y reportados: cumplido.

Resultado: P16 verificado para paginacion y filtrado ORM.
